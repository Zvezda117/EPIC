# 天线12功率异常问题记录

## 问题描述
VBaseband2Spec2的pol1（标记为"东8垂直"）功率持续偏低

## 数据证据

| 数据集 | 天线12功率 | 其他天线平均 | 差异 |
|--------|-----------|------------|------|
| crab (4304) | 0.749 | 0.845 | **-11.4%** |
| 9178 (4453) | 0.742 | 0.844 | **-12.1%** |

DC分量也偏低：
- crab: 617 (vs 其他700+)
- 9178: 625 (vs 其他700+)

## 验证一致性
✓ 问题在两批完全不同的观测数据中重现
✓ 所有其他11个通道功率正常且一致
→ **结论：硬件问题，不是数据问题**

## 排查步骤

### 1. 物理连接检查
- [ ] 检查VBaseband2输入口的pol1接头
- [ ] 测量从天线到ADC的线缆损耗
- [ ] 对比pol0和pol1的连接器状态

### 2. ADC设置检查
- [ ] 确认VBaseband2的两个通道增益设置相同
- [ ] 对比VBaseband2 vs 其他终端的配置

### 3. 天线/馈源检查
- [ ] 确认"东8"天线实际指向哪个物理天线
- [ ] 检查该天线的馈源接头
- [ ] 测试该天线的前端放大器（LNA）

## 临时解决方案

如果无法立即修复硬件，可以在软件中补偿：

```python
# 在process_crab_data.py中添加
ANTENNA_GAIN_CORRECTION = {
    11: 1.14  # 天线12（索引11）需要14%增益补偿
}

# 处理时应用
for ant_idx, gain in ANTENNA_GAIN_CORRECTION.items():
    voltages[:, :, ant_idx, :] *= gain
```

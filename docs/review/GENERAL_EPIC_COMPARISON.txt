3. 平均 gridding 核 power correction：LWA 有明确意图，通用 EPIC 没有同名等价替换。
L src/ex/cu_helpers.cuh:328-343：逐天线 kernel sum 归一化。
L :359-384 ComputeAvgGriddingKernel：跨所有编译天线求和，再把最终 kernel 的元素和归一化为 1。
L src/ex/MOFF_correlator.hpp:401-407：GPU 得到平均 kernel -> Python correction -> GPU 像素 correction。
L src/python/epic_utils.py:321-380：把平均 kernel 放入 oversampled 格点，ifft2，裁剪/转置/shift，
  取 abs(.)^2，再 reciprocal；L src/ex/fft_dx.cuh:271-274 最终乘到四平面。
因此其意图为消除电压 gridding 卷积的功率响应：图像功率除 |F(kernel_avg)|^2。
其 FFT 归一化、裁剪和 transpose 均属于约定的一部分，不能只替换 reciprocal 或只归一化 kernel。
平均单一 kernel 还隐含同质天线响应的近似；PAD、缺极化、flag 与异构天线未在该平均函数中设有效权重。

5. 可继承的依据与应隔离的历史差异。
可继承：先 grid 电压，再空间 transform，之后形成相关；卷积的电压响应平方影响功率；
  自相关取舍和有效权重必须显式记录；时间“和”与“均值”必须明确。
不能直接移植：G fft2 与 L inverse FFT 的符号/翻转、G 默认两倍 padding、
  G 权重归一化与 L 固定中间 FFT scale、G aperture-pair 模型与 L 平均 kernel、
  G UV mask/rmfit 与 L GPU image-domain auto 减法、G 电压仅 P1/P2 与 L 四平面输出。
G README.rst:9 明确是历史 Python 2 代码；这次只读静态比较，未运行该项目或 GPU。
G 异构 pair 分支 :12712-12717 本身疑似把第一个 aperture 复用到两个因子，
  因此其实现也不能未经独立代数/数值验证就作为异构天线的标准真值。

结论：这些固定版本提供算法来源证据，不提供当前 L-band 科学正确性的自动背书。
第一批 CPU 修复应使用显式电压/基线代数、已知几何 tone 与清楚的元数据契约验收；
GPU 功率校正、自相关和绝对尺度应在独立参考模型建立后分阶段处理。
